# Mobilně optimalizovaná verze

Tato verze zachovává stejný obsah, ale má výrazně upravený layout pro mobily:
- menší a čistší hlavička
- kompaktnější hero sekce
- 1 sloupec karet vín na mobilu, 2 sloupce na tabletu, 3 na PC
- košík přes celou šířku mobilu
- objednávkový formulář a potvrzení jako pohodlný bottom-sheet / modal na mobilu
- větší dotykové plochy a lepší mezery

Stačí přepsat původní soubory na hostingu těmito novými.
